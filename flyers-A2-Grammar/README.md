# Flyers A2 Grammar Practice

Cambridge Flyers (A2) 语法交互式练习工具，适用于 Claude Project / ChatGPT Custom GPT / Gemini。

## 文件说明

| 文件 | 用途 |
|------|------|
| `System_Prompt.md` | 系统提示词，粘贴到 AI 平台的 System Prompt / Instructions 中 |
| `Flyers_A2_Grammar_Guide.md` | 语法知识库，作为 AI 的参考知识上传 |

## 使用方法

### Claude Project
1. 创建一个新 Project
2. 将 `System_Prompt.md` 的内容粘贴到 Project Instructions 中
3. 将 `Flyers_A2_Grammar_Guide.md` 上传到 Project Knowledge
4. 开始对话即可

### ChatGPT Custom GPT
1. 创建一个新 GPT
2. 将 `System_Prompt.md` 的内容粘贴到 Instructions 中
3. 将 `Flyers_A2_Grammar_Guide.md` 上传到 Knowledge
4. 发布后使用

### Google Gemini
1. 创建一个新 Gem
2. 将 `System_Prompt.md` 的内容粘贴到 Instructions 中
3. 将 `Flyers_A2_Grammar_Guide.md` 作为上下文提供
4. 开始对话即可

## 功能

- 12 大语法点可选，孩子自主选择每日练习内容
- 6 种题型随机混合（选择、填空、改错、改写、排序、变形）
- 难度从基础到进阶自动递进
- 答错时提供详细语法规则解析
- 单次会话内错题记录，可随时输入 `review` 复习
- 连续答对有激励反馈
- 默认全英文，不懂时自动切换中英双语
